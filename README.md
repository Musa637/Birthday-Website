## ✨ Özellikler

* **🎁 İnteraktif Kartlar:** CSS `hover` efektleri kullanılarak oluşturulan "sürpriz" kartlar. Kullanıcı fareyi kartın üzerine getirdiğinde statik kapak resmi (`gift-cover`) kalkar ve ilgili GIF oynar.
* **🎨 Modern UI Tasarımı:**
    * **Glassmorphism:** Arka planda yarı saydam, buzlu cam efekti (`backdrop-filter`).
    * **Gradyanlar:** `linear-gradient` ile oluşturulan dinamik arka planlar.
    * **Neon Efektler:** Parlayan gölgeler (`box-shadow`) ve metinler.
* **📱 Responsive Grid:** CSS Grid yapısı sayesinde mobilden masaüstüne kadar her ekranda düzgün görünen yerleşim.
* **Badges (Rozetler):** Kişisel yetenekleri ve durumu gösteren etiket yapısı.

## 🛠 Kullanılan Teknolojiler

* **HTML5:** Semantik yapı.
* **CSS3:**
    * CSS Variables (Değişkenler)
    * CSS Grid & Flexbox
    * Keyframe Animations (`fadeIn`)
    * Pseudo-elements (`::after`)
* **Google Fonts:** 'Poppins' yazı tipi ailesi.
